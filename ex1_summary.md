### Тесты по пунктам

- **№1–2 (инъекции):** payload'ы `; id`, `$(id)`, `` `id` ``, `| id`, `&& id` → команда не выполняется; легитимный путь с пробелами архивируется.
- **№2 (код возврата):** `returncode` 0 / 1 / 127 обрабатываются предсказуемо, `stderr` попадает в лог.
- **№3 (опции):** `--checkpoint-action=exec=...`, `-C /tmp`, `--to-command=...` → `ValueError`; обычное имя каталога проходит.
- **№4 (path traversal):** `../../etc`, `/etc`, `..`, symlink наружу → отклоняются; вложенный легитимный путь проходит.
- **№5 (выходной файл):** параллельные запуски не перезаписывают друг друга; подложенный symlink не перезаписывается.

### План действий

1. **До merge:** закрыть №1–4 (инъекции, shell, опции, path traversal).
2. **В этом же PR, если дёшево:** №5 (`tempfile.mkstemp`).
3. **Отдельные тикеты:** общий хелпер безопасного запуска команд, линт-правило против `os.system`/`shell=True`, конфиг `ALLOWED_BASE`, политика хранения бэкапов.
